01 / Example request
curl https://ultrafinance.app/v1/enrich \
  -H 'Content-Type: application/json' \
  -d '{
    "description": "NORTHSTAR*COFFEE #042",
    "amount": "6.50",
    "currency": "CAD",
    "country": "CA"
  }'
# No HTTP server needed
cargo run -- enrich 'NORTHSTAR*COFFEE #042' \
  --amount 6.50 \
  --currency CAD \
  --country CA
02 / Example response200 OK
{
  "merchant": {
    "status": "matched",
    "data": {
      "id": "mer_northstar_coffee",
      "name": "Northstar Coffee",
      "country": "CA",
      "website": "https://northstar.example"
    }
  }
}

Illustrative merchant and response. A messy descriptor becomes a merchant name, stable ID, country, and website.
